Shedding Light: move the light

Move your pointer around the page (or tap on a touch screen). The pointer is a single light source, and the sphere below is re-rendered for the direction from the sphere to that light.

Reading the numbers

  • Angle from view is the angle between the light direction and the direction towards the viewer: 0° means the light is directly in front of the sphere, 90° means it is level with the page, and more than 90° means it is behind the sphere.
  • Azimuth is the light's direction around the sphere as seen on screen: 0° is to the right, 90° is straight up.
  • Direction is the unit vector from the sphere to the light, with x to the right, y up and z out of the page towards you.
  • Light height is how far the light floats above the page, in sphere radii. Negative values put it behind the page.

How it is rendered

The shading is a JavaScript port of CTSchlickGGX_render_sphere from the Shedding Light benchmark code, where it is the renderer used to estimate light direction from a sphere. It is a Cook-Torrance model with a GGX distribution and Schlick's Fresnel approximation. For each pixel with normal n, light direction l, view direction v = (0, 0, 1) and half vector h:

colour = ambient · albedo
       + ( kD · albedo / π  +  D · G · F ) · intensity · (n·l)

kD = (1 − Fv)(1 − metallic)     Fv = F0 + (1 − F0)(1 − n·v)5
D  = α² / ( π ((n·h)²(α² − 1) + 1)² )     α² = roughness4
G  = 1 / ( g(n·l) · g(n·v) )         g(x) = x + √(x²(1 − α²) + α²)
F  = F0 + (1 − F0)(1 − n·h)5

Albedo, ambient, F0 and light intensity are fixed at the starting values used in the benchmark code; the roughness and metallic sliders start at those values too. The only addition is a gamma curve so the linear result displays correctly on screen.
